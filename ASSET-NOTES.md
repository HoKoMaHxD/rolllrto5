# Visual asset notes

The backdrop `assets/ribbons.png` was generated with the built-in image-generation tool for this project. The references supplied by the user guided the dark charcoal / purple / pearl-white ribbon style. No reference screenshots are required at runtime.

Prompt: Create one reusable background asset for Discord party-game bot cards. Glossy flowing purple and pearl white sculptural ribbons, near-black charcoal background #19191f. Wide landscape 1536x1024. Smooth elegant 3D swooshes framing an empty clean dark center: one flowing purple ribbon from bottom left curls upward along left margin, another purple silk ribbon on right side, two pearl-white sculptural arcs above side ribbons. Leave the center 45 percent dark and empty for composited avatars and game icons; leave the bottom 20 percent dark and empty for dynamic text. Purple edges illuminated lilac, polished dimensional ribbons. No text, letters, watermark, people, avatar, circle, logos or buttons. Match the reference's minimal flowing ribbon identity and charcoal background.

Arabic text, the roster wheel, simple game icons and winner compositing are deterministic Canvas drawing code. Actual Discord avatars are loaded at runtime. Bundled fonts include their license notices under `assets/fonts/`.
